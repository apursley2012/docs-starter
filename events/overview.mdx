The events dashboard is the heart of PunctuOwlity — it shows every event you have saved, organized in a clean grid of cards so you can see what is coming up at a glance. Open the app at [https://apursley2012.github.io/punctuowlity](https://apursley2012.github.io/punctuowlity) and, after signing in, you land on this screen automatically.

## Dashboard layout

The events screen is arranged from top to bottom in the following areas:

| Area | What it does |
|------|-------------|
| **Topbar** | Contains the back-navigation arrow and the hamburger menu, which links to the Case Study and Articles pages. |
| **Logo** | Displays the PunctuOwlity owl logo at the top of the main content area. |
| **Upcoming Events heading** | The page heading that confirms you are on the events screen. |
| **Search bar** | A text input below the logo that lets you filter the events grid in real time by event title. |
| **Date banner** | Shows the current month and year (e.g. *April 2025*) as a visual anchor for the grid below. |
| **Category tabs** | Four filter tabs — **All Events**, **Birthdays**, **Appointments**, and **Trips** — that narrow the grid to one category at a time. |
| **Events grid** | The main content area where event cards appear in a responsive grid layout. |

## Reading an event card

Each card in the events grid surfaces the key details of one event without requiring you to open anything:

| Card element | What it shows |
|---|---|
| **Weekday abbreviation** | The three-letter day of the week the event falls on (e.g. `SAT`, `MON`). |
| **Large day number** | The two-digit date of the month displayed prominently in the centre of the card (e.g. `05`). |
| **Event title** | The name you gave the event when you created it (e.g. *Dentist* or *Jessica's Wedding*). |
| **Event time** | The start time in 12-hour format (e.g. `01:30PM`) or `ALL DAY` when no specific time was set. |
| **Alarm icon** | A bell icon that is **green** when the reminder is on and **red** when it is off. |
| **Edit button** | A pencil icon in the top-right corner of the card that opens the event in the edit form. |
| **Delete button** | A trash icon next to the edit button that removes the event immediately. |

## Sample events

When you create a new account, PunctuOwlity pre-loads a set of sample events so the dashboard is never empty on your first visit. These seed events demonstrate how different event types look on real cards:

- **Project Two Due** — an all-day event with no specific time, showing `ALL DAY` in the time slot.
- **Nich's Birthday** — a birthday event at 6:30 PM with the reminder turned on, so the alarm icon shows green.
- **Dentist** — an appointment at 1:30 PM, filed under the Appointments category.
- **Jessica's Wedding** — an event at 3:00 PM, filed under the Trips category.

You can edit or delete any of these sample events just like events you create yourself.

<Note>
  Events are sorted by date within each category view, so the nearest upcoming event always appears first in the grid.
</Note>
