The PunctuOwlity search bar lets you pinpoint any event in seconds without scrolling through every card in the grid. As you type, the events grid updates live so matching events stay visible and non-matching events disappear — no submit button required.

## Using the search bar

The search bar sits at the top of the events screen, directly below the PunctuOwlity logo and above the date banner. It is always visible while you are on the events dashboard.

To search for an event:

1. Tap the **Search events...** input field.
2. Type any part of the event title you are looking for. The grid filters in real time with every keystroke.
3. The search is **case-insensitive**, so `dentist`, `Dentist`, and `DENTIST` all return the same results.
4. Events whose titles contain your search text remain visible; all other events are hidden.
5. Clear the search field to remove the filter and restore all events in whichever category tab is currently active.

## Combining search with categories

Search and category tabs work together — the search bar always filters within the currently active category, not across the entire event list unless you are on the **All Events** tab.

- Switch to the **Birthdays** tab first, then type a name to find a specific birthday without appointments or trips appearing in the results.
- Switch to the **Appointments** tab and search for a provider name to jump straight to the appointment you need.
- Switch to **All Events** before searching if you want to search across every category at once — this is the broadest possible search scope.

This layered approach means you can narrow your results in two dimensions simultaneously: by category and by keyword.

## Tips for searching

<AccordionGroup>
  <Accordion title="Search by a person's name">
    Type part of a name associated with an event title — for example, `Nich` returns *Nich's Birthday*, and `Jessica` returns *Jessica's Wedding*. Partial matches work, so you do not need to type the full title.
  </Accordion>
  <Accordion title="Search by event type">
    Type a keyword that describes the kind of event you are looking for — for example, `dentist` surfaces your dentist appointment, and `wedding` finds any event with *wedding* in its title.
  </Accordion>
  <Accordion title="Search within a category tab for focused results">
    Activate a category tab before searching to limit results to just that category. Searching `due` on the **All Events** tab finds *Project Two Due*; switching to **Appointments** first and searching `due` returns no results, which quickly confirms the event is not filed as an appointment.
  </Accordion>
</AccordionGroup>

<Tip>
  If no events match your search query, the grid will be empty. Try a shorter or simpler search term — for example, use `dent` instead of `dentist appointment` — or switch to the **All Events** tab to broaden the search scope.
</Tip>
